**025**: The full local quality gate — type-checking, linting, formatting, tests — MUST pass locally, using the same commands CI runs, before a PR is opened. "It'll probably pass CI" is not a substitute for actually running the gate.

Rationale: Running the same checks CI runs locally catches failures before a PR is opened, so the PR's CI run confirms the result instead of finding the first failure.

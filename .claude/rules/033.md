**033**: Content that is ephemeral or not yet settled (an in-progress idea, a convention still being decided, current task state) MUST live only in session/project memory, never a repo file, until it graduates into a committed file (see rule 035).

Rationale: Unsettled or ephemeral content would go stale or mislead if committed, so it stays in memory until it's settled enough to be a repo file..

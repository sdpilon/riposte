**030**: An agent that opens a PR MUST NOT begin monitoring it without asking first — that's checked for explicitly, never started unprompted.

Rationale: a human contributor watching their own PR isn't asking anyone's permission; this specifically governs automation acting on someone else's behalf, not a rule every audience needs its own version of.

**035**: When a memory entry graduates into `.policy/`, `CONTRIBUTING.md`, or `CLAUDE.md`, its memory entry MUST be deleted or collapsed to a one-line pointer in the same change, so the two never quietly drift apart.

Rationale: Otherwise a memory entry and its committed copy drift apart, and the repo quietly disagrees with the memory it came from..

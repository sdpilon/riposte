# Quickstart: Account-Wide Progress Sweep

Validates this feature end-to-end once implemented. Not implementation
code — see tasks.md (generated by `speckit-tasks`) for that.

## Prerequisites

- Node.js 22, pnpm
- A Postgres connection string (any provider — see research.md's
  "Database / query layer")
- A GitHub token with read access to the account being assessed
- An LLM provider API key, configured per the Vercel AI SDK's provider
  setup (research.md's "LLM integration")

## Setup

```bash
pnpm install
cp .env.example .env.local   # fill in DATABASE_URL, GITHUB_TOKEN, the configured LLM provider's key
pnpm db:migrate               # Drizzle migrations — creates tracked_repos, activity_records, assessments, runs, run_items
pnpm dev
```

## Local quality gate (same commands CI runs)

```bash
pnpm typecheck   # tsc --noEmit
pnpm lint        # next lint
pnpm format:check
pnpm test        # vitest
```

## Validate the feature

1. Trigger a population run:
   ```bash
   curl -X POST http://localhost:3000/api/runs
   ```
   Expect `202 Accepted` with a `runId`.

2. Trigger it again immediately:
   ```bash
   curl -X POST http://localhost:3000/api/runs
   ```
   Expect `409 Conflict` — confirms FR-011 (no overlapping runs).

3. Poll progress:
   ```bash
   curl http://localhost:3000/api/runs/<runId>
   ```
   Expect `reposProcessed` to climb across repeated calls without blocking
   on the first `POST` — confirms FR-010 (async, incremental).

4. Once `status: "completed"`, open the dashboard
   (`http://localhost:3000`) and confirm:
   - Every eligible repo shows a status tier, completion estimate, and a
     verdict that names specific evidence (User Story 1).
   - Any fork/archived/no-README/no-activity repo shows its specific
     exclusion reason, not just an excluded flag (User Story 2).

5. Re-run the population run with no underlying repo changes
   (`POST /api/runs` again after step 4 completes) and confirm no repo's
   `assessments` row count increases — confirms FR-006 (change-detection)
   and spec.md's SC-003.
